版权信息与资源使用说明

这是一篇帮助文档，用于指示某些重要信息

感谢你访问 Benjamin's Blog

我十分重视你的个人隐私，并始终遵循必要、透明、最小化的原则处理与网站访问相关的信息

作为个人博客，本站不会主动收集与你身份无关的信息，也不会出售、出租或交易任何用户数据

适用范围

本隐私政策适用于 Benjamin's Blog 及其相关网站服务

访问本站即表示你已知悉本隐私政策所说明的内容

本站可能收集的信息

访问日志

当你访问本站时，网络服务器、内容分发网络（CDN）或相关基础设施可能会自动记录部分技术信息，包括但不限于：

  • IP 地址（可能经过匿名化处理）
  • 浏览器类型及版本
  • 操作系统信息
  • 设备类型
  • 页面访问记录
  • 引荐来源（Referrer）
  • 访问时间
  • HTTP 请求信息

上述信息主要用于：

  • 网站安全防护；
  • 故障诊断；
  • 性能优化；
  • 访问统计与分析

本站不会利用上述信息识别你的真实身份

评论信息

如果你在本站发表评论，评论系统可能会收集：

  • 昵称；
  • 邮箱地址（如填写）；
  • 网站地址（如填写）；
  • 评论内容；
  • IP 地址；
  • 浏览器 User-Agent 信息

上述信息仅用于：

  • 评论展示；
  • 垃圾评论过滤；
  • 网站安全维护

除法律法规另有规定外，本站不会公开你的邮箱地址

访问统计

为了了解网站运行情况，本站可能使用访问统计服务

统计信息通常包括：

  • 页面浏览量（PV）
  • 独立访客（UV）
  • 浏览器及设备类型
  • 页面停留时间
  • 来源页面

统计数据主要用于改进网站内容和优化访问体验，不用于建立个人画像或开展精准广告投放

Cookie 与本地存储

本站可能使用 Cookie、LocalStorage、SessionStorage 或其它浏览器本地存储技术，以实现以下功能：

  • 保存主题模式（浅色/深色）；
  • 保存用户界面偏好；
  • 记住部分浏览设置；
  • 支持评论系统；
  • 提升网站访问体验

这些数据通常保存在你的设备中，不会上传至本站服务器，除非相应功能确有需要

如你不希望使用 Cookie，可通过浏览器设置进行管理。但关闭相关功能后，本站部分功能可能无法正常工作

第三方服务

为了提供完整的网站功能，本站可能使用第三方服务，包括但不限于：

  • Cloudflare（内容分发、安全防护及网络优化）
  • GitHub Pages（网站托管）
  • Twikoo（评论系统）
  • Umami（网站访问统计，如启用）
  • NeoDB（内容数据服务）

上述服务可能依据各自的隐私政策处理与你访问本站相关的部分信息

本站无法控制第三方服务的数据处理方式，建议你同时查阅其对应的隐私政策

第三方链接

本站可能包含指向其它网站或第三方服务的链接

这些网站拥有各自独立的隐私政策和数据处理方式

当你离开本站后，你的数据处理将不再受本隐私政策约束

数据安全

本站将采取合理措施保护网站及相关数据的安全，包括但不限于：

  • 使用 HTTPS 加密传输；
  • 使用内容分发网络（CDN）及安全防护服务；
  • 定期维护网站程序及依赖组件；
  • 尽可能减少个人信息收集

上述服务可能依据各自的隐私政策处理与你访问本站相关的部分信息

本站无法控制第三方服务的数据处理方式，建议你同时查阅其对应的隐私政策

你的权利

如果你曾在本站提交评论或其它个人信息，你有权：

  • 查询相关信息；
  • 更正相关信息；
  • 请求删除相关信息（法律法规另有规定的除外）
  • 尽可能减少个人信息收集
